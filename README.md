# LATTICE

An adaptive, model-driven tutor for Data Structures and Algorithms. Instead of tracking
"solved / not solved", LATTICE maintains a live probabilistic model of which fine-grained
skills you have mastered, and when you fail a problem it reads your actual code to infer
*which specific skill broke*.

This repository is the **Phase 1 vertical slice**: a fully runnable, client-side proof of the
core loop. The full design (cloud backend, hardened sandbox, LLM credit assignment, deep
knowledge-tracing model, A/B eval) lives in `LATTICE_BUILD_PROMPT.md`.

## What is real in this slice

| Piece | Status |
|---|---|
| Python execution + grading | Real. Runs in-browser via Pyodide (the browser is the sandbox). |
| Mastery model | Real. Bayesian Knowledge Tracing (Corbett & Anderson, 1994) per skill. |
| Frontier scheduler | Real. Picks the next problem at the edge of competence (desirable difficulty band). |
| Spaced review | Real. Mastery decays over time and resurfaces for retrieval. |
| Knowledge graph | Real. 70 skills across 21 categories with prerequisite edges, laid out by depth. |
| Problem bank | Real. 78 problems, 312 tests, all graded by execution. Browsable platform view. |
| Credit assignment | **Heuristic stand-in** for the LLM layer. Same output contract; swap in a model later. |
| Deep model (DKT) + cloud + A/B | Deferred to later phases. |

## Content pipeline

The knowledge graph and problem bank are generated by `tools/genbank.py`, the single source of
truth. Reference solutions are **executed** there to compute expected test outputs, so every test
is correct by construction (no hand-written answers to get wrong). This mirrors how the full system
would mass-produce content. Adding a problem is one `reg(...)` call; regenerate with:

```bash
python tools/genbank.py
```

It writes `src/data/{kcs,edges,bank}.json` and reports any reference that fails to execute or
produce JSON-serializable output. Structured inputs stay JSON-friendly (trees as nested lists
`[val, left, right]`, graphs as adjacency lists, grids as matrices) so the in-browser grader runs
unchanged.

## Run it

```bash
npm install
npm run dev
```

Open the printed URL. First code run downloads the Python runtime from a CDN (a few seconds).
State persists in localStorage; reset from the command palette.

## Using it

- `Ctrl/Cmd + K` opens the command palette (primary navigation).
- `Lattice` shows your knowledge state as a vector graph. Fill = P(mastered). Amber outline = frontier.
- `Practice` is the core loop: write Python, `Ctrl/Cmd + Enter` to run. On failure, the readout
  localizes the broken skill, marks the fault line, and ticks the lattice.
- `Instruments` shows the learning trace, the credit-attribution honesty metric, per-skill mastery,
  and the activity log.

## Design

Aesthetic is a deliberate "amber-phosphor console meets sharp modern Swiss grid". Hard rules,
enforced throughout: no rounded corners, no purple, no emoji, no soft blurred shadows, no sidebar.
Two themes (`phosphor` dark, `blueprint` light), CRT scanline overlay, keyboard-first.

## Stack

React + Vite + TypeScript, Zustand, Pyodide. No UI component library (the design system is custom).
