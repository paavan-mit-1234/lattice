# LATTICE

An adaptive practice platform for Data Structures and Algorithms. You solve coding problems in the
browser, get instant feedback, and the app keeps track of how well you know each underlying skill so
it can point you toward what to practice next.

It runs entirely in the browser. Your Python solutions execute locally, and your progress is saved on
your device, so there is no account or setup beyond opening the page.

## Features

- **In-browser code editor** with syntax highlighting, auto-indent, undo/redo (`Ctrl/Cmd + Z`), and
  bracket-aware editing.
- **Run vs Submit** — run your code against the visible example tests first, then submit against the
  full hidden test suite. You can also run against your own custom input.
- **Problem bank** organized into Solved / Unsolved and Easy / Medium / Hard, with search and
  category filters across topics like arrays, hashing, sliding window, graphs, trees, DP, and more.
- **Skill map** that visualizes the topics as a connected mind-map you can zoom, pan, and expand, so
  you can see what you have covered and what is still ahead.
- **Adaptive recommendations** — the app estimates how comfortable you are with each skill and
  suggests problems at the right level instead of too easy or too hard.
- **Hints and editorials** — progressive hints when you are stuck, and a worked approach (plus a
  reference solution on many problems) once you have solved it or chosen to reveal it.
- **Complexity analysis** — runs your solution on growing inputs and estimates its time complexity
  from the measured growth.
- **Submission history** — every submission for a problem is logged, and you can diff a past attempt
  against your current code.
- **Multiple languages** — Python runs and grades in the browser; C, C++, and Java are available in
  the editor with starter templates for writing and studying (see Roadmap for running them).

## Getting started

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the printed local URL. The first time you run code, the browser downloads a small Python
runtime from a CDN (a few seconds); after that it is cached.

To build a production bundle and preview it:

```bash
npm run build
npm run preview
```

## How it works

- The app is a static, client-side site. There is no backend; everything runs in your browser.
- Submitted Python is executed in a sandboxed background worker, so even a buggy or infinite-looping
  solution is timed out gracefully instead of freezing the page.
- Your progress (which problems you have solved, your skill estimates, submission history) is stored
  in the browser's local storage. Clearing site data resets it; there is also a reset option in
  settings.

## Project structure

```
src/
  components/   UI views (editor, problem browser, skill map, insights)
  engine/       grading, scheduling, hints, complexity analysis
  data/         the generated knowledge graph and problem bank (JSON)
  workers/      background code-execution worker
tools/
  genbank.py    generates the problem bank and skill graph
```

## Content

The skill graph and problem bank are generated by a single script, `tools/genbank.py`. Each problem
defines a reference solution that is executed at build time to produce the expected test outputs, so
the tests are correct by construction. Regenerate with:

```bash
python tools/genbank.py
```

This writes the JSON data the app reads at runtime. Adding a problem is a single entry in the script.

## Tech stack

React, TypeScript, and Vite, with Zustand for state. Python execution in the browser is powered by
Pyodide. The interface is built without a component library; the design system is custom.

## Design

A deliberate "amber-phosphor console meets sharp modern grid" look. Consistent rules throughout: no
rounded corners, no purple, no emoji, no soft shadows, no sidebar. Two themes (a dark phosphor mode
and a light blueprint mode), an optional CRT scanline overlay, and keyboard-first navigation via a
command palette (`Ctrl/Cmd + K`).

## Roadmap

Planned improvements:

- **Hosted version** — deploy the site so it is usable from a public URL, not just locally.
- **Run C / C++ / Java** — add a server-side code-execution service so the compiled languages can be
  run and graded, not just written.
- **Accounts and cloud sync** — optional sign-in so progress follows you across devices instead of
  living only in one browser.
- **Bigger problem bank** — broaden topic coverage and add more problems per topic.
- **Editorials for every problem** — extend worked solutions to the full bank.
- **Responsive layout** — a usable experience on tablets and smaller screens.
